# מי כתב את זה?

משחק מסיבה חינמי בעברית, מותאם למחשב ולטלפון. כל משתתף כותב משפטים בסתר, מצטרפים באמצעות קוד חדר ומנחשים מי כתב כל משפט. אין צורך בייצוא WhatsApp, בהרשמה או בתשלום.

## משחקים

1. המארח מקליד שם ופותח חדר.
2. שולחים לחברים את הקישור או הקוד (אפשר גם לסרוק QR).
3. ממתינים בלובי. המארח לוחץ ״מתחילים משחק״ ורק אז כולם עוברים למסך הכתיבה.
4. במסך כתיבה מרכזי ללא סרגל צד, כל משתתף כותב משפט אחד בדיוק, ממלא ארבעה שמות חופשיים ומסמן את התשובה הנכונה. השמות יכולים להיות של כל אדם, גם מי שאינו במשחק. אין כפתור ״עוד משפט״.
5. כולם רואים את אותו משפט וארבע אפשרויות. יש 25 שניות לבחור, והמשחק מתקדם כשכל מי שיכול להצביע בחר או כשהזמן נגמר. מי שהוסיף את המשפט צופה בשאלה שלו.
6. במסך הסיום מופיעים הניקוד, כל המשפטים, ארבע האפשרויות לכל משפט, התשובה הנכונה ושם המשתתף שהוסיף אותו. כל בחירה נכונה שווה 1,000 נקודות.
7. בסיום אפשר להתחיל סיבוב כתיבה חדש באותו חדר. כל אחד ממלא משפט אחד וארבעה שמות חדשים, והניקוד נשמר בין הסיבובים.

יש מצב הדגמה ללא חיבור לחדרים. קיצורים: 1–4 לבחירת תשובה, M לצליל, F למסך מלא.

## תשתית חינמית

אתר סטטי שניתן לארח ב-GitHub Pages עם דומיין אישי. החיבור נעשה ב-WebRTC באמצעות שירות האיתות החינמי של PeerJS. המארח צריך להשאיר את העמוד פתוח ואת המכשיר ער. סגירה או רענון של עמוד המארח מסיימים את החדר. אורח יכול להתחבר מחדש מאותה לשונית, בלי לאבד ניקוד.

חיבור ישיר עלול להיחסם ברשתות סלולריות, ברשתות ארגוניות או ב-NAT מסוים. במקרה כזה נסו Wi-Fi אחר. אין שרת TURN בתשלום ואין התחייבות לזמינות שירות האיתות החיצוני. קוד החדר הוא קוד הזמנה, לא סיסמה למידע רגיש.

שמות ומשפטים נשמרים בזיכרון של המארח בזמן המשחק; אין מסד נתונים של הודעות. שאלות של אחרים והתשובה הנכונה לא נשלחות לאורחים לפני החשיפה. המארח מנהל את החדר ולכן מסוגל טכנית לקרוא את כל השאלות. PeerJS מקבל את פרטי האיתות הדרושים לחיבור, וה-CDN וספק הגופן מקבלים בקשות רגילות לטעינת קבצים.

## פיתוח

אין התקנת תלויות. Node.js 20 ומעלה:

```sh
npm start
npm test
```

כתובת מקומית: http://127.0.0.1:4173

מפרסמים את השורש של ענף main ב-GitHub Pages. הגדרת Custom domain יוצרת קובץ CNAME. אין להכניס סודות או אסימוני API לקוד הציבורי.

זהו מימוש עצמאי של משחק ניחוש לחברים, בהשראת רעיון המשחק שסופק. אין קשר לאתר המקור ולא הועתקו ממנו קוד או נכסים.
